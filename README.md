## ⌨️ પંચિંગ માસ્ટર કીબોર્ડ શોર્ટકટ્સ (Master Shortcuts):

| શોર્ટકટ કી | કાર્ય અને પંચિંગ અસર |
|---|---|
| `Spacebar` | **Select Tool** મોડમાં પાછા ફરવા |
| `H` | **Shape Edit** - નોડ્સ, પોઇન્ટ્સ અને હેન્ડલ્સ સુધારવા |
| `E` | **Edit Stitch** - સિંગલ ટાંકો સુધારવા કે ડીલીટ કરવા |
| `B` | **Break** - લાઇન કે ઓબ્જેક્ટને વચ્ચેથી તોડવા |
| `J` | **Weld / Join** - બે શેપ્સને જોડીને એક બનાવવા |
| `R` | **Mirror** - બે ક્લિક આપી આડી કે ઊભી નકલ કરવી |
| `Q` | **Center Object** - ઓબ્જેક્ટને બરાબર મધ્યમાં લાવવા |
| `Shift + X` | **Swap Nodes** - Start અને End પોઇન્ટ અરસપરસ બદલવા |
| `Ctrl + D` | **Duplicate** - ઓબ્જેક્ટની તુરંત નકલ બનાવવા |
| `Alt + Shift + V` | **Paste in Place** - મૂળ જગ્યાએ જ ચોક્કસ પેસ્ટ કરવી |
| `Alt + ->` | **Step Copy** - ચોક્કસ અંતરે લાઇનસર કોપી કરવી |
| `Alt + CapsLock` | **Beads / Sequin Rotate** - ૯ ડિગ્રી ના એંગલે ફેરવવા |
| `Alt + Y` | **Object Cut** - બીડ્સ બ્રેકડાઉન કટ કરવો |
| `Alt + B` | **Beads Split** - બીડ્સ લાઇન વિભાજિત કરવી |
| `Ctrl + Home` | **Set Machine Origin** - $X=0, Y=0$ (DR250) લોક કરવું |

## 🏭 ઇન્ડસ્ટ્રિયલ પ્રોડક્શન પેરામીટર્સ (Factory Standards):

- **સાટિન ડેન્સિટી (Satin Density):** `0.38 - 0.42 mm` (સામાન્ય દોરો), `0.45 mm` (ઝરી દોરો).
- **તતામી સ્ટીચ લંબાઈ (Tatami Pitch):** `3.5 - 4.0 mm`.
- **બીડ્સ ટાંકા લંબાઈ (Beads Pitch):** મોતી વ્યાસ $+ 0.3 \text{ mm}$ (દા.ત. 2.5 mm મોતી માટે 2.8 mm ટાંકો).
- **સિક્વિન સ્પેસિંગ (Sequin Pitch):** 5 mm સિક્વિન માટે મચ્છી સ્કેલ = `2.5 mm` (50% ઓવરલેપ).
- **ઓટો-જમ્પ સ્પીડ (Auto Jump):** `5.0 mm` થી મોટા અંતર પર ટ્રાવેલ રન મૂકવો.
